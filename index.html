FEATURES

为深度书写而生

从标题到脚注，从代码到公式，XinText 覆盖 Markdown 全语法，并以原生性能承载长文档写作。

全特性 Markdown

标题、强调、列表、引用、代码、表格、任务列表、脚注、数学公式、Emoji、HTML 内联，应有尽有。

文件树导航

左侧目录树直接打开、新建、重命名、拖拽移动，底部集成回收站，误删可一键还原。

文档大纲

右侧目录自动解析标题层级，点击即可跳转，长文档结构一目了然。

全文检索

在整个工作目录下按内容查找文件，秒级定位所需段落，不再翻箱倒柜。

历史路径

自动记录最近打开的文件夹，一键回到上次的写作现场，路径缺失自动标灰。

标签页多开

多文件并行编辑，重命名或移动时路径自动同步，已打开的标签不会失效。

VIEW MODES

三种视图，按需切换

无论是专注阅读、即时预览，还是源码掌控，XinText 都为同一段文字提供最合适的视角。

01

阅读模式

纯净排版输出，沉浸式阅读体验，适合校对与终稿审阅。

02

预览编辑

所见即所得，左侧编辑右侧实时渲染，写作与排版同步进行。

03

源码编辑

直接掌控 Markdown 原文，精确控制格式与结构，进阶用户首选。

ARCHITECTURE

原生，而非 Electron

基于 Wails v3 构建，使用 Go 后端 + 系统 WebView，告别臃肿的浏览器打包。

  • 轻量体积系统 WebView 渲染，无需打包完整浏览器，安装包与内存占用大幅下降。
  • Go 原生后端文件系统、回收站、导出、搜索等高 IO 操作由 Go 直接处理，稳定高效。
  • 系统级集成托盘图标、全局快捷键、关闭确认、资源管理器定位等原生能力无缝衔接。
  • Vue 3 前端组件化界面与 Pinia 状态管理，响应迅速，定制灵活。
Wails v3

Go × Vue × WebView

把后端的稳健与前端的轻盈，统一在同一个原生窗口里。
